# Student Result Management System

A beginner-friendly Python project for managing student details and calculating student results.

## Features

- Add a new student
- View student details
- Update student marks
- Delete a student
- Calculate total marks
- Calculate percentage
- Calculate average marks
- Calculate grade
- View all stored student details

## Concepts Used

- Python
- Dictionaries
- Nested dictionaries
- `while` loops
- `if / elif / else`
- `for` loops
- User input
- Dictionary methods
- Basic calculations

## Subjects

The current version manages marks for:

- Python
- Java
- DSA

## How to Run

Make sure Python is installed, then run:

```bash
python Student_Result_Management.py
